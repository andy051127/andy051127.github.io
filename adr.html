ADR-001
Flutter 선택
2026-04-13 확정
배경

모바일 앱 개발 플랫폼 선택이 필요했습니다. Android 네이티브 단독 개발과 크로스플랫폼 프레임워크(Flutter, React Native) 중에서 검토했습니다.

결정

Flutter + Dart 채택

이유
  • 단일 코드베이스로 Android / iOS 동시 지원 — 유지보수 비용 절감
  • Hot Reload 기능으로 UI 반복 개발 속도 극대화
  • Material 3 위젯 기본 제공으로 디자인 일관성 확보
  • pub.dev 생태계의 풍부한 패키지 — sqflite, fl_chart, table_calendar 등 즉시 활용 가능
결과

Android 실기기(SM S937N, Galaxy S24 FE)에서 정상 동작 확인. iOS는 현재 미테스트 상태이나 코드 구조상 추가 작업 최소화로 지원 가능.

ADR-002
Riverpod 상태관리
2026-04-13 확정
배경

Flutter 상태관리 라이브러리 선택이 필요했습니다. Provider, Bloc, Riverpod 세 가지를 검토했으며 각각의 장단점을 비교했습니다.

결정

flutter_riverpod 채택

이유
  • 컴파일 타임 타입 안전성 — 런타임 에러를 빌드 단계에서 사전 차단
  • Provider 대비 DI(의존성 주입) 없이도 전역 상태에 안전하게 접근 가능
  • FutureProvider로 비동기 상태를 선언적으로 처리 — 로딩/에러/데이터 상태 자동 관리
  • ref.invalidate로 세밀한 리빌드 제어 — 불필요한 렌더링 방지
결과

레이어별 Provider 분리(HomeViewModel, RoutineViewModel, StatsViewModel 등)로 테스트 용이성 확보. 보일러플레이트 코드를 최소화하면서도 명확한 데이터 흐름 구현.

ADR-003
Local-First + Firebase 선택적 동기화
2026-04-20 확정
배경

데이터 저장 전략을 수립해야 했습니다. 클라우드 의존 방식(Firebase Firestore only)과 로컬 우선(Local-First) 방식을 비교 검토했습니다. 루틴 및 통계 데이터 특성상 오프라인 환경에서도 완전한 동작이 필요했습니다.

결정

SQLite(sqflite)를 primary 저장소로, Firebase Firestore를 선택적 클라우드 백업으로 채택

이유
  • 오프라인 완전 동작 보장 — 네트워크 연결 없이도 루틴 체크, 스트릭, 통계 등 100% 기능 사용 가능
  • 앱 초기화 속도 향상 — 로컬 DB 즉시 읽기로 네트워크 지연 없는 빠른 시작
  • Firebase 미설정/미로그인 상태에서도 앱 정상 실행 (graceful fallback) — 가입 없이도 완전한 기능 제공
결과

Firebase 로그인 없이도 완전한 기능을 제공합니다. Google 로그인 시 로컬 SQLite 데이터를 Firestore에 자동 동기화하며, 멀티 디바이스 지원이 가능합니다.

ADR-004
flutter_timezone 제거
2026-05-11 기술 부채
배경

로컬 푸시 알림 예약 시 정확한 타임존 처리가 필요했습니다. flutter_local_notifications와 함께 flutter_timezone 패키지를 사용하던 중 Android 빌드 에러가 발생했습니다.

문제

flutter_timezone 1.0.8이 내부적으로 사용하는 Registrar API가 현재 프로젝트의 Kotlin 버전에서 제거되어 컴파일 에러 발생.

오류 메시지: Unresolved reference 'Registrar'

결정

flutter_timezone 패키지 제거 후 타임존을 'Asia/Seoul'로 하드코딩

이유
  • DevFlow는 한국 단일 시장을 타겟으로 하는 앱이므로 타임존 하드코딩이 실질적인 기능 손실 없음
  • 패키지 업스트림 수정을 기다리는 것보다 즉각적인 빌드 정상화가 우선
  • 코드 복잡도 감소 — 패키지 의존성 하나 제거
결과

빌드 정상화 확인. 단, 해외 사용자 사용 시 알림 시간 오차가 발생할 수 있습니다. 향후 flutter_timezone 패키지가 업데이트되거나 대체 패키지 적용 시 개선 예정입니다.
